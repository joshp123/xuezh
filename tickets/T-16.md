# T-16: HelloChinese cram review MVP

## Goal
Import canonical HelloChinese and Travel Survival rows, seed review state from Pleco score metadata, and review them in a fast sentence-based cram loop.

## Deliverables
- `hellochinese import` imports canonical Pleco-text rows in learning order.
- `travel import` imports Travel Survival Pleco-text rows.
- `pleco score-import` seeds score/recency metadata without using Pleco card text as canonical content.
- `hellochinese audio-backfill` fills missing sentence audio after import.
- `cram audio-backfill` fills missing sentence audio for the unified deck.
- `cram next` returns the next due card.
- `cram grade` applies the simple cram schedule.
- `learner state` exposes the full canonical deck and live score facts as compact LLM context.
- Sentence audio can be generated during import when the existing TTS backend is available.

## Acceptance criteria
- Import is idempotent.
- Spaced Hanzi from the source is cleaned before storage, TTS, and card display.
- Existing generic `review` commands keep their behavior.
- No recommendation or ranking fields are emitted.

## Test plan
- Unit tests for import, idempotence, sentence cleaning, audio path storage, next-card ordering, and grade scheduling.
- CLI smoke test against a temporary workspace.

## Notes
Updated to a unified canonical cram deck with Pleco score metadata seeding and a minimal local React web wrapper.
