# T-16: HelloChinese cram review MVP

## Goal
Import normalized HelloChinese rows and review them in a fast sentence-based cram loop.

## Deliverables
- `hellochinese import` imports JSONL rows in learning order.
- `hellochinese audio-backfill` fills missing sentence audio after import.
- `cram next` returns the next due card.
- `cram grade` applies the simple cram schedule.
- Sentence audio can be generated during import when the existing TTS backend is available.

## Acceptance criteria
- Import is idempotent.
- Spaced Hanzi from the source is cleaned before storage, TTS, and card display.
- Existing generic `review` commands keep their behavior.
- No recommendation or ranking fields are emitted.

## Test plan
- Unit tests for import, idempotence, sentence cleaning, audio path storage, next-card ordering, and grade scheduling.
- CLI smoke test against a temporary workspace.

## Notes
Implemented as a CLI-first HelloChinese cram engine with a minimal local React web wrapper.
Verified import against the real 689-row corpus with `--audio none`; first card returns cleaned `你是龙大。`.
